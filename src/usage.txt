ChatGPT Wallpaper bridge — Wallpaper Engine backgrounds inside the official
Windows ChatGPT / Codex desktop app, with an in-app control panel.

Usage: node src/bridge.mjs [command] [options]

Daily driver: open the app, run "start", then click the floating ◉ button in
the app — the 壁纸引擎 panel (壁纸/播放/效果/轮播/扩展/系统) controls everything.

Commands:
  start                 Attach to the app and inject wallpaper + panel.
                        Stays in the foreground serving media (Ctrl+C quits).
  stop                  Remove the layer from the app and stop the bridge.
  status                Bridge state, playlists, live page state.
  list [--all]          Wallpaper Engine library (videos; --all adds scene/web
                        previews), with content rating and hidden marks.
  select <id>           Switch to a library wallpaper now.
  next | prev           Switch within the active playlist.
  play | pause | toggle Playback of the current video wallpaper.
  set <tokens...>       Replace the ACTIVE playlist (ids / paths / titles).
  add <tokens...>       Append to the active playlist.
  clear                 Empty the active playlist.
  hide <id> | unhide <id>  Hide/restore library cards (files untouched).
  rotate                --interval <sec>  --order sequential|shuffle
  live                  --on | --off  --fps 15|30|60   Scene/Web real-time
                        rendering (WebWallGL). Off = preview-image fallback.
  playlist              ls | create --name N | use <key> | rename --name N | delete <key>
  preset                ls | save --name N | apply --name N | delete --name N
  probe                 Inject connectivity probes; check the bridge log for
                        fetch/WebGL/iframe capability reports.
  autostart [--off]     Start the bridge hidden at login (Task Scheduler
                        logon task + Startup-folder shortcut -> inline
                        PowerShell launcher, no script file; logs to
                        autostart.log; no console window, no elevation).
                        Also registers the watchdog at login and starts it
                        immediately. If neither fires at boot, check your
                        security tool's startup-item manager (火绒等).
  watchdog [off]        Start/stop the watchdog: while the app is open it
                        relaunches the bridge whenever it dies (security-
                        tool kills, taskkill, ...), so the wallpaper no
                        longer vanishes until the next login. Restarts are
                        logged to watchdog.log. Note: with the watchdog
                        running, "stop" is undone within ~a minute if the
                        app is open — use "watchdog off" first.
  import <files...>     Import local jpg/png/gif/mp4/webm/mov as wallpapers
                        (copied to %LOCALAPPDATA%\ChatGPT-Wallpaper\uploads).
  import-we [--apply N] List playlists from the official Wallpaper Engine
                        client's config.json; --apply <n|名称> imports one as
                        the active bridge playlist.
  mascot                --on | --off  --form whale|maid|portrait|vector|custom
                        --size 0.6..2   Pull-cord mascot at the top edge:
                        --file <img>    drag sideways to move, pull down or
                                        click for panel. --file sets a custom
                                        image as the mascot (form=custom).
  avatar                --user <img> [--assistant <img>]  Chat-row avatars
                        (built-in glyphs when unset). --clear / --off.
  fx                    Tune visuals (no flags = show current):
    --opacity  --brightness  --contrast  --saturate  --blur   wallpaper layer
    --dim                          dark overlay above wallpaper (暗化 0..0.85)
    --pan-x --pan-y --zoom         framing (object-position %, scale 1..3)
    --rate --volume                video playbackRate, volume 0..1
    --flip / --no-flip             horizontal mirror
    --transition <t>               cut|fade|slide|wipe|iris|zoom|bars
    --transition-dir <d>           left|right|up|down (slide/wipe/bars)
    --transition-speed <x>         0.4..3 (multiplies --fade-ms base)
    --panel-alpha --panel-alpha-dark --panel-blur --composer-alpha
    --auto-tint / --no-auto-tint   glass tint follows wallpaper brightness
    --font <family>                app UI font ('' = app default)
  help                  Show this text.

Config: ~/.chatgpt-wallpaper/config.json (NOT %LOCALAPPDATA% — the Codex app
is MSIX-packaged and Windows would show Codex-hosted terminals a redirected
copy; auto-migrated from the legacy AppData location on first run).
A running bridge hot-reloads config edits and pushes them to the app ~2.5s.

Requires: Windows, official ChatGPT or Codex desktop app open, Node.js >= 22.
The app build must expose its local DevTools endpoint (current builds do).
